# Arquivos já aprovados para processamento

Coloque aqui **somente** MP4s previamente anonimizados e revistos visualmente.

- `source_file`: gravação já sem usernames, e-mails, chaves, mensagens, notificações ou dados pessoais.
- `hook_file`: vídeo de gancho com permissão/licença de uso.
- Gravações originais devem ficar fora do GitHub.

O renderizador mantém máscara opaca configurada na receita, mas a aprovação prévia reduz riscos no armazenamento remoto. Não publique automaticamente.
